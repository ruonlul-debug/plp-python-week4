# PLP Python Functions Assignment

* **functions.py** - Contains the `double`, `is_pass`, and `greet` function definitions along with their test print statements.
* **welcome.py** - Contains the original `welcome` greeting function and test cases for Amina, Brian, and Fatuma.

### Reflection
The hardest function to write was `greet` because it required combining multiple variables and punctuation string elements together correctly while supporting an optional default argument. Using an f-string made it much easier to format the greeting, comma, name, and exclamation mark cleanly.
